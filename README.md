## App Store React Project

## Description
This is a React-based [App Store] project where users can view different applications, see their ratings, downloads, and descriptions.  
Users can [install] apps, which are then saved in the browser’s localStorage, and also*uninstall them later.  
It dynamically updates both the app details page and the installed apps list in real time.

---

## Features
-  Search apps by name  
-  View downloads, reviews, and average ratings  
-  Install and Uninstall functionality using localStorage  
-  Persistent data — remains even after page reload  
-  Responsive UI with Tailwind CSS  
-  Dynamic Ratings chart display
